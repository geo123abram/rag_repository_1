Document Chunking

Each chunk is converted into a numerical embedding vector.

3

Similarity Search

The query embedding is compared with document embeddings.

4

Retrieved Context

Most relevant chunks are retrieved from the vector database.

5

Prompt Augmentation

Retrieved chunks are injected into the final LLM prompt.

6

LLM Final Response

The language model answers using the retrieved knowledge.
